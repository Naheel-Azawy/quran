* Quran
A minimal Quran for CLI, TUI, web, and Android written in C (and JavaScript for web, and little Java for Android).

** TUI
#+begin_src shell
  $ make install
#+end_src

** Web
#+begin_src shell
  $ make web
#+end_src

#+begin_src shell
  $ make web-serve
#+end_src

#+begin_src shell
  $ make web-push SERVER=me@example.tld
#+end_src

** Android
#+begin_src shell
  $ make android ANDROID_DEBUG=0
#+end_src

#+begin_src shell
  $ make android-install ANDROID_DEBUG=0
#+end_src

** Dependencies
- ~gcc~
- ~node~
- ~emcc~ for web
- ~fribidi~ - optional for TUI
- ~fzf~ - optional for TUI
- Android studio - optional for Android
